2026 Sales Performance Analysis | Excel & Power BI

Project Overview

This project focuses on analysing 2026 sales performance using Microsoft Excel and Power BI. The goal was to transform raw sales data into meaningful business insights through data cleaning, preparation, analysis, and interactive visualisation.

Project Objectives

- Clean and prepare raw sales data for analysis.
- Identify and address data quality issues.
- Analyse revenue, orders, products, and regional performance.
- Develop key performance indicators (KPIs).
- Build an interactive Power BI dashboard to support business decision-making.

Tools Used

- Microsoft Excel: Data cleaning, transformation, formulas, and preliminary analysis.
- Microsoft Power BI: Data visualisation, KPI development, and interactive dashboard creation.

Data Cleaning and Preparation

The dataset was examined for:

- Missing values.
- Inconsistent regional names.
- Extra spaces in customer names.
- Dates stored as text.
- Invalid date entries.
- Negative sales transactions.

Cleaning activities included standardising regional names, removing unnecessary spaces, converting dates where possible, and calculating missing revenue where the required information was available.

Unresolved or questionable records were retained for further investigation rather than making unsupported assumptions.

Key Insights

- Port Harcourt recorded the highest regional revenue.
- Monitors generated the highest revenue among the top-performing products.
- August, September, and October accounted for approximately 92.4% of recorded revenue.
- The dashboard highlights differences in revenue performance across regions and products.

Note: The monthly trend excludes transactions without valid dates.

Dashboard Features

The interactive Power BI dashboard includes:

- KPI cards.
- Revenue by region.
- Top 5 products by revenue.
- Monthly revenue trend.
- Interactive region and product slicers.
- Key business insights and recommendations.

Recommendations

1. Investigate regional differences to identify opportunities for improving sales.
2. Maintain sufficient stock of high-revenue products.
3. Investigate missing and invalid transaction dates to improve reporting accuracy.
4. Monitor monthly sales trends to support better business planning.
